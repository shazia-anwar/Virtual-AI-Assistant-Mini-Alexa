# Mini Alexa - Virtual AI Assistant

## Project Overview

Mini Alexa is a text-based virtual assistant developed using Python. It performs basic tasks and demonstrates fundamental AI concepts, including rule-based logic and a simple perceptron.

It works offline in the terminal and uses rule-based logic.

## Features
- Personalized greeting
- Current date and time
- Basic calculator
- Random motivational quotes
- Random jokes
- Random facts
- Number guessing game
- Help menu
- Rule-based activity recommendation
- Simplified perceptron demonstration
- Graceful exit

## Technologies Used
- Python
- Python Standard Library

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   python main.py
